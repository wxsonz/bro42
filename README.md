# ft_bro (`bro`)

**ft_bro** (command: **`bro`**) is a pedagogical pair-programming, guidance, and testing companion for 42 **Libft** (Version 19.2).

---

## 🚀 Quick Start

```bash
# 1. Install ft_bro globally
./install.sh

# 2. Run from anywhere in your Libft directory:
cd ~/my_libft
bro                  # Tests current directory, prints verbose results, opens Web Dashboard
bro ft_split         # Tests only ft_split
bro macro            # Runs build, relink, and symbol audits
bro --no-web         # Terminal-only mode
```
